# AI-Powered Threat Detection & Security Monitoring Platform

An intelligent cybersecurity monitoring platform that combines real-time packet analysis, threat detection, system monitoring, and interactive dashboards using AI and modern web technologies.

---

# Features

##  Real-Time Network Monitoring
- Live packet capturing and traffic analysis
- Detection of suspicious network activity
- Monitoring of incoming and outgoing traffic

##  AI-Based Threat Detection
- Identifies unusual behavior patterns
- Detects possible cyber attacks and anomalies
- Threat classification and alert generation

##  Interactive Dashboard
- Visual analytics with charts and graphs
- Real-time threat statistics
- Traffic distribution monitoring
- System activity overview

##  Alert & Logging System
- Security event logging
- Threat notifications
- Attack history tracking

##  Full Stack Architecture
- Frontend dashboard built with modern UI
- Backend APIs for processing and analytics
- Packet capture and monitoring modules
